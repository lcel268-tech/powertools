# PowerTools

[![Website](https://img.shields.io/badge/Website-ptools.site-blue)](http://ptools.site)

中文: 汽车调校工程师工具箱。在线生成马力曲线图、分析CSV数据流、匹配ECU文件。
English: ECU tuning toolbox for automotive engineers. Dyno chart generation, CSV data analysis, ECU file matching.

## 功能 / Features

### 马力图生成 / Dyno Chart
- 上传 YourDyno CSV，自动生成马力/扭矩曲线图
- Upload YourDyno CSV, auto-generate HP/TQ curves
- 峰值功率/扭矩自动识别
- 多文件对比、品牌Logo定制

### CSV 数据流分析 / Data Log Analysis
- MHD / Bootmod3 / Autotuner / Ktuner / VCDS
- 数据滤波去噪、异常值剔除
- Filtering, noise reduction, outlier removal

### ECU 工具 / ECU Tools
- BMW ECU A2L/XDF 快速匹配
- Bosch MED17/EDC17/MG1/MD1 校验和修复
- XDF to WinOLS JSON 转换
- WinOLS NOREAD 签名去除
- 5000+ 车型调教数据查询

## 快速开始 / Quick Start

访问 ptools.site 即可使用，无需注册。
Visit ptools.site to start instantly. No registration required.
